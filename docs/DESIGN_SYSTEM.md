# Design system

Drop is a small, precise shelf. It should feel calm and useful rather than like a compressed dashboard.

| Token | Value / purpose |
| --- | --- |
| Canvas | #ffffff, pure white |
| Ink | #14233b, main text |
| Accent | #2d5be3, primary action and Drop mark |
| Quiet text | #5c697d and nearby tested accessible shades |
| Dividers | #e4eaf2, cool gray hairlines |
| Collection hints | Six controlled colors; text remains readable independently |
| Typography | Local system fonts, no remote font request |
| Popup | 404 × 594 CSS px, bounded shelf scroll |
| Expanded library | Shared implementation in a responsive browser tab |
| Icons | Small fixed SVG strokes and custom open-circle d mark |

Separate the brand, short introduction, deliberate save action, search, modes, list and quiet storage footer. Use rows and light separators to make saved content easy to scan. The Pro sheet is part of the extension, explains the one-time offer and shows truthful configuration status.

Use native buttons, labeled inputs, native dialogs/details, visible focus, keyboard access and reduced-motion preferences. Saved content is escaped text. Confirmation copy names the actual effect; Delete all requires typing DELETE. Failed form submission keeps the current draft visible.

The portfolio uses the same pure white and blue with large, spare typography and a screenshot of the actual interface. No invented reviews, vanity numbers, decorative glow or stock product mockups. Screenshots are taken from the built UI, not generated illustrations.
