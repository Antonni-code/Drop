# Implementation phases

1. `define drop` — scope, architecture, design and acceptance criteria.
2. `build clip library` — schema, guarded storage, free tier, background commands, clipboard and extension shell.
3. `add pro tools` — collections, favorites, ordering, imports, exports and deliberate Quick Paste.
4. `add license service` — Creem integration, signed receipts, activation, refresh and deactivation, release configuration gates.
5. `polish drop` — final interface, keyboard and accessible states, rendered visual QA.
6. `prepare release` — behavior tests, browser verification, packaging, ABOUT, README, PRD, privacy and deployment guides.
7. `add drop page` — portfolio landing page, policies and project entry, targeted verification.

Use short commit subjects without names or co-author trailers. Work remains local until the requested public repository exists. The available writing-plans skill was searched for but is not installed; this document is the implementation plan.
